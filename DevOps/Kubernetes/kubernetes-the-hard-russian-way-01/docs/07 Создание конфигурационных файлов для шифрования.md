Kubernetes хранит разные данные: состояние кластера, настройки приложений и секреты. При этом Kubernetes умеет **[шифровать]((https://kubernetes.io/docs/tasks/administer-cluster/encrypt-data)) эти данные на диске**, чтобы они были защищены, даже если кто-то получит доступ к хранилищу.

В этой лабораторной работе мы создадим **ключ шифрования** и **[конфигурацию шифрования](https://kubernetes.io/docs/tasks/administer-cluster/encrypt-data)**, которые нужны для защиты объектов Kubernetes `Secret`.

## Создание ключа шифрования

Генерируем ключ шифрования:

```bash
export ENCRYPTION_KEY=$(head -c 32 /dev/urandom | base64)
```

## Создание Encryption Config File

Создаём папку `configs`:

```bash
mkdir configs
```

И скачиваем в нее файл `encryption-config.yaml`:

```bash
wget 
```

Создаём файл конфигурации шифрования `encryption-config.yaml`:

```bash
envsubst < configs/encryption-config.yaml \
  > encryption-config.yaml
```
