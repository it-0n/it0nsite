# 1. Подготовка виртуальной сети
 
 VMware® Workstation Pro 26H1 на Linux есть возможность создавать дополнительные виртуальные сети. На Windows такой возможности нет.

>Этот шаг вы можете пропустить и создать виртуальные машины стандартным способом для вашего гипервизора.

1. Запустите Virtual Network Editor

    Вы должны увидеть нечто подобное:

    ![Virtual Network Editor](img/VMWareVirtualNetworkEditor.png)

    > У меня уже пристуствуют разные подсети, но для проекта создадим ещё одну. 

2. Нажмите кнопку `+ Add Network...` и введите значения как на скриншоте:

   ![Add Vritual Network](img/AddVirtualNetwork.png)

   И нажмите кнопку `+Add`.

   После этого будет создана новая виртуальная сесть с именем `vmnet88`:

   ![Add Vritual Network](img/NewVirtualNetwork.png)

3. Задайте подсеть `192.168.88.0/24` для `vmnet88` как на скриншоте:
   
   ![Add Vritual Network](img/SubnetIPVirtualNetwork.png)

   И нажмите кнопку `Save`. После этого подсеть будет задана и окно закроется.

```bash
sed -i 's/^# *ru_RU.UTF-8 UTF-8/ru_RU.UTF-8 UTF-8/' /etc/locale.gen && \
```

## 3.5. Настраиваем статический ip, route, dns

Первому серверу задаим ip 192.168.108.11/24.

Gate 192.168.88.2

DNS 1.1.1.1 и 8.8.8.8

Узнаем имя сетевого интерфейса:

```bash
ip -br a
lo               UNKNOWN        127.0.0.1/8 ::1/128 
ens32            UP             192.168.88.128/24 fe80::fb87:1566:1f5e:7ba7/64 
```
Редактируем файл настроек сетевых интерфейсов:

```bash
vim /etc/network/interfaces
```

И приводим его к такому виду:

```toml
# This file describes the network interfaces available on your system
# and how to activate them. For more information, see interfaces(5).

source /etc/network/interfaces.d/*

# The loopback network interface
auto lo
iface lo inet loopback

# The primary network interface
# allow-hotplug ens32
# iface ens32 inet dhcp

auto ens32

iface ens32 inet static
    address 192.168.88.11/24
    gateway 192.168.88.2
    dns-nameservers 1.1.1.1 8.8.8.8
```

Настраиваем DNS редактируя файл `/etc/resolv.conf`

```bash
vim /etc/resolv.conf
```
И прописываем туда DNS сервера, например:

```bash
nameserver 77.88.8.8
nameserver 1.1.1.1
```

Перезапускаем сеть:

```bash
systemctl restart networking
```
> **Внимание!** После этой команды терминал может зависнуть, так как поменялся ip. Поэтому надо просто подключиться уже по новому адресу который мы задали.

Проверяем:

```bash
ip -br a
lo               UNKNOWN        127.0.0.1/8 ::1/128 
ens32            UP             192.168.88.11/24 192.168.88.128/24 fe80::fb87:1566:1f5e:7ba7/64
```
Можно сделать `ping ya.ru` чтобы проверить что сеть доступна.

После этого выключаем виртуальную машину:

```bash
shutdown now
```
